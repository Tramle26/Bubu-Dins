# Prototype prompt set

Mode: built-in image-generation tool. Use case: `ui-mockup`.

## Shared direction

Create a high-fidelity 16:9 desktop PathMX financial-learning game screen at a
1440x900 design target. Use the supplied Bubu mascot for identity, the
professor for Dr.Bos, the bus map for texture/color, and the sketches for
information hierarchy. Combine soft textured 2D storybook/gouache illustration
with clean, accessible HTML-style interface panels for college students. Use
forest green, sage, warm cream, gold, terracotta, and pale sky blue. Keep type
large and readable. Include a compact Bubu/Learn/Storyworld/My collection/coin/
profile shell. Make every control practical to reproduce in HTML/CSS. Avoid
casino imagery, sponsor logos, glossy 3D, photorealism, mobile framing,
watermarks, gibberish text, tiny labels, and dense dashboard charts.

## 01 Home dashboard

Show Bubu welcoming Alex in an illustrated grove. Make a dominant Continue
card for Housing choices / Next: Try it, compact Housing and Investing topic
cards, a saved-plan summary, and a prominent Visit Storyworld action. It should
feel like the opening screen of a cozy learning adventure.

## 02 Housing journey

Show a compact winding path through a forest/campus scene with exactly three
large stops: Learn completed, Try it current, and Review locked. Place the Bubu
bus near the current stop and Bubu with a blank sign. Include progress,
Continue, and List view. Keep stops as legible UI controls rather than labels
baked into scenery.

## 03 Storyworld

Show one coherent near-orthographic illustrated town with six destinations:
Bank, Hospital, House, College, Supermarket, and Mall. College is central.
House is selected and opens a practical information/purchase card with the
learning goal, 40-coin cost, Not now, and Spend 40 coins to start. Mark preview
buildings Coming soon and include List view.

## 04 House simulation

Show Rent or buy after graduation? with stay, down-payment, and loan-term
controls; Rent/Buy comparisons for monthly cash, upfront cash, and ending
position; an assumptions disclosure; and a stable right-side Dr.Bos panel.
Dr.Bos asks what changes when the learner moves after two years. Include a
response field, Hint, Send, and three labelled rubric states: Costs, Term, and
Context. Clearly label it Fictional learning simulation.
