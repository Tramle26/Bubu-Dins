# Save your journey

This starter uses local learner sign-in. Open the local preview on the computer
running Bubu, choose **Sign in**, then pick **Annastasiia** or **Lilia**.

[Open local preview](http://localhost:3017/)

Hosted previews can be used for browsing. Local account switching only works
on localhost. The team will need to configure real credentials before saving
learner progress on a shared deployment.
