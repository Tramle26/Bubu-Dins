# Check and demo

A good handoff is a small working experience another teammate can understand.

## Run the project checks

In the project terminal:

```sh
bun run check
bun run typecheck
bun run test
```

If something fails, give your agent the actual error and the change you just
made. Fix the cause, then rerun the affected check.

## Try it as a learner

- Read the lesson: does its activity practice the idea it actually teaches?
- Open your screen at laptop and phone widths. Check text, buttons, art, and scrolling.
- Use Tab and Enter. In a lesson overlay, Escape should close it and return focus to the link.
- Complete an activity as Annastasiia, reload, and check saved progress. Lilia should remain separate.
- Save a small source edit with the page open. Check that it updates without losing unrelated input or focus.
- Check links and images, including the standalone lesson page as well as its overlay.

## Show your teammate

Explain what the learner does, what changed, and what is still a placeholder.
Give them the page link and source filename. Demonstrate the activity rather
than only showing the code.

Keep the next task small. A well-tested lesson, room, or sprite is a useful
contribution even when the whole game isn't finished.
